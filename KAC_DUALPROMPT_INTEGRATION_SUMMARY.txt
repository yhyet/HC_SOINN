使用方法
--------
1. 基本使用:

       "use_kac": true,
       "kac_config": {
           "grid_min": -2.0,

       }
   }

2. 运行实验:
   python main.py --config exps/dualprompt_kac.json

技术细节
--------
1. 分类器位置:
   - DualPrompt的分类器在backbone内部（self.head）
   - 通过timm.create_model创建模型时传递KAC参数

2. 参数传递路径:
   args → get_backbone → timm.create_model → VisionTransformer.__init__ → self.head

3. 与Codaprompt的差异:
   - Codaprompt: 分类器在CodaPromptVitNet中（self.fc）
   - DualPrompt: 分类器在backbone内部（self.head）
   - 参数传递需要通过timm.create_model
